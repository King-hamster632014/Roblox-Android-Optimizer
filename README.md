# Roblox Android Optimizer

This repository contains a simple Roblox performance configuration and installation links for Android tools that may help you apply it correctly.

## What is included

- ClientAppSettings.json — Roblox settings for lower visual load and better performance
- Cx Install Link.txt — link to install Cx File Explorer
- Shuziku install — link to install Shizuku

## Purpose

This project is meant to help improve Roblox performance on Android devices by adjusting client settings and making it easier to access the app folder where these settings are stored.

## Important notes

- Back up your current Roblox settings before modifying anything.
- This is meant for Android devices and may not work the same on every Roblox version.
- Some settings may vary depending on the app version or device model.
- If something does not work, restore the original file.

## Instructions

1. Install Shizuku
   - Open the file named Shuziku install.
   - Follow the link and install the Shizuku app on your Android device.
   - Complete the setup steps shown in the app.

2. Install Cx File Explorer
   - Open the file named Cx Install Link.txt.
   - Install Cx File Explorer from the provided link.

3. Open Cx File Explorer
   - Launch Cx File Explorer on your Android device.
   - Navigate to the app data area for Roblox.

4. Locate the Roblox settings file
   - Find the Roblox app directory.
   - Look for a file named ClientAppSettings.json.

5. Replace the settings file
   - Open the current Roblox ClientAppSettings.json file.
   - Replace it with the contents from this repository’s ClientAppSettings.json.
   - If the file does not exist, create it in the correct Roblox folder.

6. Restart Roblox
   - Fully close Roblox.
   - Reopen it and check whether performance and visuals are improved.

7. Adjust if needed
   - If the game is still too heavy, lower more settings or restore the original file.
   - Keep a backup of the original file so you can revert later.

## Recommended use

- Best for lower-end Android devices
- Useful for smoother gameplay and lower lag
- Use only if you are comfortable editing app settings files

## Final reminder

This repository is a small optimization helper, not a full app. Use it carefully and always keep a backup of your original Roblox settings before making changes.
